Unity & AR Foundation Production Architecture

Step-by-step setup for iOS (ARKit) & Android (ARCore) targeting phones & headsets

1. Required Unity Packages (Package Manager)

  • com.unity.xr.arfoundation (v5.1+)
  • com.unity.xr.arkit (iOS ARKit Provider)
  • com.unity.xr.arcore (Android ARCore Provider)
  • com.unity.render-pipelines.universal (URP for 60/90 FPS mobile AR)

2. Scene Hierarchy Setup

  • XR Origin (AR Rig) with AR Camera, AR Tracked Pose Driver
  • AR Session + AR Session Origin
  • AR Plane Manager (Detection Mode: Horizontal for Tabletop/Floor)
  • AR Raycast Manager (Touch-to-place on detected plane surface)

3. FBX 3D Model Optimization Checklist

  • Mesh Compression: Set to High in Model Import Settings.
  • Read/Write Enabled: Disabled to save 50% CPU RAM.
  • Normals: Calculate (Smooth Angle: 60°) for crisp architectural edges.
  • Draw Call Reduction: Combine stone trims and minarets with GPU Instancing.
  • LOD Group: LOD0 (full stucco details ~25k tris) & LOD1 (silhouette ~6k tris).

4. Touch Gesture Interactions

  • 1-Finger Drag: Orbit / rotate Charminar around Y-axis.
  • 2-Finger Pinch: Smoothly scale between 0.2m (tabletop) and 2.0m (room scale).
  • Single Tap on Beacon: Highlight architectural hotspot & trigger voice audio.

C# AR Tabletop Placement Snippet (ARPlacementManager.cs)

using System.Collections.Generic;
using UnityEngine;
using UnityEngine.XR.ARFoundation;
using UnityEngine.XR.ARSubsystems;

public class CharminarARPlacement : MonoBehaviour {
    [SerializeField] private ARRaycastManager raycastManager;
    [SerializeField] private GameObject charminarPrefab;
    private GameObject spawnedMonument;
    private static List<ARRaycastHit> hits = new List<ARRaycastHit>();

    void Update() {
        if (Input.touchCount > 0 && Input.GetTouch(0).phase == TouchPhase.Began) {
            Vector2 touchPos = Input.GetTouch(0).position;
            if (raycastManager.Raycast(touchPos, hits, TrackableType.PlaneWithinPolygon)) {
                Pose hitPose = hits[0].pose;
                if (spawnedMonument == null) {
                    spawnedMonument = Instantiate(charminarPrefab, hitPose.position, hitPose.rotation);
                } else {
                    spawnedMonument.transform.position = hitPose.position;
                }
            }
        }
    }
}
